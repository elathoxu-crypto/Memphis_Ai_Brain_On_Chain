## The discovery that mattered

**The cockpit's brain is already renderer-agnostic.**

```
grep -n "ratatui" crates/memphis-tui/src/app.rs     -> nothing
grep -n "ratatui" crates/memphis-tui/src/client.rs  -> nothing
```

8 277 LOC of state machine, command router, worker orchestration and stream
handling, with zero terminal dependency. Only `ui.rs` + `widgets/` (the renderer,
~1 630 LOC) import Ratatui. The model is semantic too — `LineTone` maps to styles
only in `widgets/mod.rs::tone_to_style`.

So a second surface needs a second **renderer**, not a second brain. That turned
"build a GUI" from a multi-week project into "extract a crate, then write a
renderer".

## Six more, all measured on the host

- **Two chat stacks; only one streams.** Rust: `ChatStreamEvent::Text`. TypeScript:
  `stream: false` (`src/providers/index.ts:284`). Both write `operator_chat_messages`
  with complementary columns. A GUI on the TS path would have had **no streaming**.
- **The input caret was never rendered.** `Hide` on enter, `Show` only on exit, and
  `set_cursor_position` appeared nowhere in the crate. The prompt was one row, so
  long prompts were silently truncated.
- **The input was strictly append-only.** `Backspace` called `String::pop()`;
  `Left`/`Right` were unbound. A typo in the middle could not be fixed.
- **Scrollback was unsearchable.** 1 200-line cap, no find, no paging — while live
  sessions held 1 447 / 782 / 737 messages.
- **The host protocol serialises everything** (`tui-host/index.ts:80-85`), so a GUI
  could not poll status during a chat.
- **ADR-010's "missing system libraries" was wrong for this host.** All five Tauri-v2
  dependencies are present; the old finding came from Debian `apt` package names
  applied to an Arch box.

## The seam that already existed

`src/infra/tui-host/` is a versioned NDJSON RPC over stdio with 37 capabilities,
and `interaction.ts:98` says it is *"the stdio-json protocol mode used by GUI
consumers"*. A Tauri GUI is a **second client of a protocol that was written for
it** — with a contract test that had never had a second client.

Layer 1 of the design: a real caret, an editable multi-line prompt, `Ctrl+F`

167 unit tests, the Rust workspace green, no clippy warnings in the touched files.

## The lesson worth keeping

Two findings about measurement, both learned the hard way:

1. **crossterm reads the terminal size from `/dev/tty`, not stdout.** A child that
   inherits a controlling terminal lays out for *that* terminal while writing to
   the pty. Every pty-based TUI measurement needs `setsid` — otherwise you measure
   the wrong screen.
2. **Ratatui renders differentially.** `> hello` never appears as a contiguous
   substring in the byte stream, because only changed cells are rewritten. Measure
   escape sequences, not text.

And one about processes: **a PR marked "merged" is not the same as "done".** The
automerge merged the branch as it stood when the PR was *opened* — ten hours
before the later commits existed. Checking the content of `origin/main` (not the
PR status) is what caught it.
